# ERT 출동 대응 V2

지금까지 확정된 최신 요구사항만 반영해 새로 구성한 React + Vite 프로젝트입니다.

## 실행

```powershell
npm install
npm run dev
```

## 배포용 빌드

```powershell
npm run build
```

## 주요 기능

- 출동 슬롯 기본 3개, 추가 및 최소 3개까지 자유 삭제
- 출동별 독립 자동저장과 현재 출동만 전체 초기화
- 제목 영문 자동 대문자 변환
- 현상·성상·환자 여부·주변 작업사항 최종 포함 체크
- 성상 pH·Leak량·Leak속도 3개 독립 입력
- 흡입환자·접촉환자 수와 다중행 환자 상세정보
- 가스알람 문자·사내메신저 알림 형식 자동 판독 및 현상 작성
- Gas Alarm 전용 대응 문구 5개
- 한 중간보고에 대응 문구 여러 개 누적 추가
- 같은 출동 사용 이력 저장·재사용
- 최종 대응 정리에서 중복 문장 제거
- 종료 문구 선택 및 전체 복사

## 불러오기

상단의 `불러오기` 버튼에서 일반 대응 정리 또는 가스알람 문자를 현재 출동에 적용할 수 있습니다.

### 대응 정리 불러오기

기존 대응 정리 전체를 붙여넣으면 현재 출동 슬롯에 자동 적용됩니다.

- 제목, 현상, 성상, 환자 여부, 주변 작업사항 자동 분리
- 번호가 붙은 대응 내용은 각각 독립 중간보고로 생성
- 불러온 대응 내용은 같은 출동 사용 이력에도 추가
- 원인분석 및 상황 종료 문구 자동 복원
- 현상에 `Alarm` 또는 `알람`이 있으면 Gas Alarm 자동 체크
- 표준 Gas Alarm 문장은 단발/다발, 호기/환경감지기, 대상, 등급, 수치, 단위, 추가 건수까지 복원
- 일부 항목이 인식되지 않아도 현상 원문은 그대로 보존

### 가스알람 문자 불러오기

1. 상단 `불러오기`를 누릅니다.
2. 문자 또는 지원되는 사내메신저 알림 전체를 붙여넣습니다.
3. `현재 출동에 적용`을 누릅니다.
4. 앱이 가스알람 문자와 일반 대응 정리를 자동 판별합니다.

자동 입력 항목:

- 제목: 건물·층·BAY·기둥
- 현상: 대상 설비·가스명·등급·수치·단위
- 가스 출동 상태 활성화 및 전용 대응 문구 표시

건물명 변환:

- 평택 2L동 → `P2L`
- 평택 3L동 → `P3L`
- P3 복합동/평택 복합3동 → `복합3동`
- P4 복합동/평택 복합4동 → `복합4동`

문자에 BAY 정보가 없으면 임의로 만들지 않습니다. 물질 상세정보, 센서 번호, 노드 정보는 가져오지 않습니다. 현상 영역의 기존 Gas Alarm 수동 버튼은 제거되었고, 가스알람 문자를 자동 인식하면 현상 옆에 `가스 출동 작성 중` 상태가 표시됩니다.

주변 작업사항은 `대응 정리에 포함`이 체크되어 있으면 최종 정리에 출력됩니다. `없음`이 체크된 경우에도 `-. 주변 작업사항: 없음`으로 표시됩니다. 기존 `-. 작업사항:` 형식도 불러오기에서 계속 인식합니다.

## PWA 설치 및 오프라인 사용

이 버전은 Chrome/Edge에서 설치 가능한 PWA로 구성되어 있습니다.

1. Vercel 등에 HTTPS로 배포합니다.
2. Chrome에서 배포 주소를 엽니다.
3. 주소창의 설치 아이콘 또는 메뉴의 `앱 설치`를 선택합니다.
4. 온라인 상태에서 앱을 한 번 완전히 연 뒤에는 오프라인에서도 다시 실행할 수 있습니다.

### 업데이트

새 코드를 배포하면 앱을 다음에 온라인으로 열거나 화면으로 복귀할 때 업데이트를 확인합니다. 새 서비스 워커가 발견되면 새 버전으로 전환하며 화면이 한 번 자동 새로고침될 수 있습니다. 입력 데이터는 localStorage에 저장되므로 일반적인 코드 업데이트와 새로고침으로 삭제되지 않습니다.

서비스 워커 캐시 구성을 크게 바꿀 때는 `public/sw.js`의 `APP_VERSION`도 증가시키는 것이 좋습니다.

### 아이콘

- 일반 아이콘은 둥근 사각형 바깥쪽이 투명합니다.
- Android용 maskable 아이콘은 전체 배경을 어두운 남색으로 채워 흰색 모서리가 보이지 않습니다.

## 자주 쓰는 대응 문구 다중 선택

- 각 문구 왼쪽 체크박스로 여러 문구를 동시에 선택할 수 있습니다.
- 체크한 순서대로 선택 문구가 목록 상단과 중간보고 입력창 상단에 배치됩니다.
- 문구 완성 입력값은 중간보고 textarea에 실시간으로 반영됩니다.
- 각 선택 문구는 `접기/펼치기`로 다시 수정할 수 있습니다.
- 문구 글자를 직접 누르는 기존 단일 선택·`입력창에 추가` 방식도 유지됩니다.
